# 远控安全：查清"谁能远程操作这台机器"

> 起因：出现「鼠标自己动」，同时本机传感器反复报告某进程可疑外连。
> 结论前置：**鼠标自己动最常见的解释不是木马，而是本机装了远程控制软件且被人连上了。**
> 这类软件为穿透 NAT 全部**主动外连厂商中转云**，所以在防火墙日志里长得和普通出站
> HTTPS 一样 —— 必须专门去查。

---

## 1. 工具

```powershell
# 控制台摘要（只读，不卸载、不停服务、不断连接）
.\.venv\Scripts\python.exe tools\remote_access_audit.py

# 同时写报告
.\.venv\Scripts\python.exe tools\remote_access_audit.py --report

# 原始 JSON（便于二次分析）
.\.venv\Scripts\python.exe tools\remote_access_audit.py --json logs\remote_access_audit.json
```

查四件事：

1. **已知远控产品**：进程 / 服务 / 自启项（Run、启动文件夹、计划任务）/ 安装记录
2. 每个在跑的产品：完整路径 + **数字签名状态**（区分正版与被篡改的同名程序）
3. **被控证据**：扫它们自己的日志目录，找"被远程连接/会话"的痕迹与时间
4. 远程访问通道：RDP 是否开启、远程协助/快速助手状态

产品表覆盖：向日葵/AweSun、TeamViewer、AnyDesk、RustDesk、ToDesk、UU远程、
远辰 GameViewer、VNC 类、Chrome Remote Desktop、Quick Assist、Splashtop/LogMeIn/Radmin/
ScreenConnect/Ammyy/DWAgent/AeroAdmin 等。

**为什么用子串而不是精确匹配进程名**：这类软件版本间会改可执行文件名
（向日葵从 `SunLoginClient` 改成 `AweSun` 就是实例）。只用精确名会漏。

## 2. 风险定性规则

| 条件 | 风险 |
|---|---|
| 只安装、未运行 | 低 |
| 进程正在运行 | 中 |
| 配置了开机自启 | 中（若同时运行则升为高） |
| 有正在运行的服务（可在无人值守时接受连接） | **高** |
| 日志里存在"被控/会话"记录 | **高** |
| 可执行文件签名异常 | **高** |

## 3. 怎么判断"是不是有人连过"

⚠ **先看连接记录，再卸载** —— 卸载之后日志就没了，而日志是判定"谁连过"的唯一证据。

| 产品 | 去哪看 |
|---|---|
| 向日葵 / AweSun | 登录 Oray 账号后台看**连接记录/登录日志**（来源、时间、时长）。这是最直接的证据 |
| GameViewer | `D:\tools\yuanchen\GameViewer\log\` 下 `*_controlled_*.slog`（被控）/ `*_controller_*.slog`（主动连别人）的时间分布与大小 |
| 其他 | 对应产品的"会话历史"或日志目录 |

**读日志文件名的要点**：文件名里的 `controlled` 是**角色**（本机作为被控端），
不是"刚发生了一次会话"。判断有没有真实会话要看**文件内容/大小变化**，以及
`connection_log_*`（连接）与 `streamer_log_*`（画面流）两类文件的增长情况。
一个持续运行的被控端服务会一直往自己的 `streamer_log_*` 写 —— 那**不代表**此刻有人在看你的屏幕。

判断依据（按可信度排序）：
1. 产品账号后台的连接记录（最可信，有来源与时长）
2. `connection_log_*` 在"你不在电脑前"的时间段有明显增长
3. 画面流日志（`streamer_log_*`）在那个时间段显著增大

## 4. 两种情形，两条路

### A. 是你自己装的、自己在用

不是入侵。但仍建议按第 5 节收紧配置 —— 远控软件等于给这台机器开了一扇**联网的门**。

### B. 不是你装的，或不是你连的

按**入侵事件**处置：

1. **立刻断网**（拔网线 / 关 WiFi），保留现场
2. **保留证据**：先导出上面那些日志、再动手清理（清理会销毁证据）
3. **改密码 + 开两步验证**：远控账号、邮箱、以及这台机器上所有用过的账号
    （远控被登录过，机器上的凭据都可能已泄露）
4. **离线查杀**：用当前杀软全盘扫描（注意：若 Defender 被其它杀软接管，它自己不会扫）
5. **重装系统**是最稳妥的处置 —— 管理员权限下无法穷举对方留下的所有后门，
   查干净的概率远低于重装。重装前备份**数据**（不要备份可执行文件与配置文件）
6. 排查范围内的其他机器（同一远控账号登录过的设备）

### 卸载清单（确认不用了再执行）

```powershell
# 1) 先确认注册了什么（这三条都是只读）
Get-Service | Where-Object { $_.Name -match '(?i)sunlogin|oray|gameviewer|anydesk|teamviewer|rustdesk|todesk' } |
    Select-Object Name,DisplayName,Status,StartMode
Get-ItemProperty 'HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run',
                 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run' |
    Format-List
Get-ChildItem 'C:\Windows\System32\Tasks' -Recurse -EA SilentlyContinue |
    Where-Object { $_.Name -match '(?i)sunlogin|oray|gameviewer' } | Select-Object FullName

# 2) 销号 / 退出登录（在软件界面里做，这步比卸载更重要：
#    单纯卸载软件，账号侧的授权记录还在）

# 3) 卸载（用软件自带卸载器或「设置 → 应用」）
#    卸载后再跑一次本审计工具，确认服务与自启项都消失了
.\.venv\Scripts\python.exe tools\remote_access_audit.py
```

## 5. 加固清单（长期）

**远控软件本身**

- [ ] 不用时**彻底退出**（很多工具退出界面后**服务仍在跑**，仍可接受连接）
- [ ] 关闭「无人值守访问」，或设置**独立的高强度访问密码**（与本机登录密码不同）
- [ ] 开启**两步验证**与**登录通知**
- [ ] 限制「允许访问的 IP」白名单（支持的工具有）
- [ ] **不要**把识别码/验证码给任何人（含"客服"—— 这是最常见的骗局入口）
- [ ] 定期去看账号后台的**连接记录**，不认识的会话立即改密

**系统层面**

- [ ] RDP 保持关闭（除非确实需要；本机实测已关闭 `fDenyTSConnections=1`）
- [ ] 远程协助/快速助手不需要时关闭
- [ ] 保留一个**独立的管理通路**（WiFi / 另一张网卡），别让唯一通路是被远控的那条 ——
      否则一旦出事你会同时失去"处置"与"取证"的通路

**检测层面**

- [ ] 本机传感器（`tools/net_sensor.py`）已在看外连，但它看到的是"某进程外连某 IP"
- [ ] 定期（例如每周）跑一次本审计工具 —— 它补的正是"这台机器能不能被远程控制"这个视角
- [ ] 若接了旁路 IDS，注意远控软件走的是**出站 443**，报文侧看不出"这是远控"

## 6. 本次审计**没有**覆盖的范围

别把"没发现"当成"已排除"：

- 非管理员运行时读不到安全事件日志（登录 4624 / 进程创建 4688 / 服务安装 7045）
- 不做全盘病毒扫描，也不替代杀软
- 只查**已知**远控产品；自研/改名的远控工具不会被产品表命中
- 「不能控屏但能读写文件」的窃密类恶意软件不在本工具范围内
- 鼠标自行跳动的**硬件**原因（触摸板脏污/故障、多设备干扰、无线接收器问题）
  同样不在软件审计范围内 —— 可用"插外接鼠标 + 禁用触摸板"跑一天来排除
